# На вырост: чего в курсе нет и где про это прочитать

Источник — DESIGN-v1.md §3.4 (последний абзац) и §11.

Claude Code умеет больше, чем проходит курс. Это сделано нарочно: маршрут держит только то, что новичку нужно каждый день, иначе курс распух бы вдвое и половина настроенного стояла бы без дела. Ниже — темы, **сознательно оставленные за бортом**. Ничего из этого знать не обязательно; если какая-то строка откликнулась — идите в официальную документацию Claude Code (**code.claude.com**), в соответствующий раздел.

В конце каждого этапа курс предлагает пройтись по этому списку и отметить в журнале: **включил / отложил / не надо** (§4.7). Три четверти строк честно окажутся «не надо» — это нормальный результат, а не пробел.

## Автоматика и правила

| Тема | В двух словах | Где читать (раздел документации) |
|---|---|---|
| **hookify** | Готовый помощник, который делает хук из вашей фразы «хочу, чтобы каждый раз…». Курс учит писать хуки руками и по одному — так понятнее, что именно срабатывает | хуки (hooks) |
| **Routines, scheduled tasks в Desktop** | Задачи по расписанию: «каждый понедельник собери отчёт». Требует, чтобы вы уже доверяли своей автоматике | Desktop, планирование задач |
| **Статус-строка (statusline)** | Настраиваемая строка внизу окна: модель, ветка, расход. Красиво и бесполезно, пока не выработалась привычка смотреть `/context` | статус-строка (statusline) |
| **Output styles** | Смена манеры ответов Claude. Легко ломает предсказуемость уроков, поэтому вне маршрута | output styles |
| **Managed settings** | Настройки, которые задаёт организация и пользователь не может изменить. Тема для рабочего компьютера в компании, не для личного | настройки (settings) |
| **Песочница (sandbox)** | Изоляция, в которой команды выполняются с урезанными правами. Курс упоминает её, но не настраивает | песочница (sandboxing) |

## Помощники и проверки

| Тема | В двух словах | Где читать |
|---|---|---|
| **advisor** | Экспериментальный советчик, который смотрит на вашу работу со стороны. **Нужен собственный ключ Anthropic API** — то есть отдельные деньги помимо подписки; курс денег не тратит без явного «да» и лишних счетов не заводит | advisor |
| **`/insights`** | Сводка о вашей работе с Claude Code в виде HTML-страницы. Считается **по текущей машине** и **тратит лимиты подписки** — поэтому курс её не предлагает | стоимость и лимиты (costs) |
| **evals** | Автоматические проверки для плагина: «на такой запрос он обязан вести себя так». Инструмент авторов; в курсе используется только изнутри, для собственной проверки безопасности | оценки плагинов (plugin evals) |
| **Готовые скиллы `claude-code-setup`, `claude-md-management`** | Встроенные помощники по первичной настройке и по уходу за `CLAUDE.md`. Курс делает то же самое руками — чтобы вы понимали каждую строчку, которую у вас правят | скиллы (skills) |

## Своё и большое

| Тема | В двух словах | Где читать |
|---|---|---|
| **Свой плагин** | Собрать собственный набор скиллов и агентов и ставить его одной командой — как этот курс | плагины (plugins) |
| **Свой MCP-сервер** | Написать пристройку, которая даст Claude инструменты вашего сервиса. Курс учит **подключать** готовые серверы (M10), а не писать их | MCP |
| **Команды агентов (agent teams) сверх демонстрации** | В M13 они показываются один раз. Регулярная работа ими — это экспериментальная возможность, только терминал, заметно больший расход лимитов и изменившееся поведение делегирования | команды агентов (agent teams) |
| **Режим `-p` и Agent SDK** | Запуск Claude Code без диалога — из скрипта, по расписанию, внутри другой программы. Отдельный мир со своими правилами безопасности | CLI, SDK |
| **GitHub Actions** | Запуск Claude в облаке по событию в репозитории (пришёл PR — проверь). Нужен git и репозиторий на GitHub | GitHub Actions |

## Как этим пользоваться

1. Дошли до конца этапа — откройте этот список и разметьте: включил / отложил / не надо.
2. Захотели что-то включить — не ставьте молча. Тот же порядок, что в курсе: понять, что делает и как выключить → копия → «да» → правка → строка в `changes.md` (`procedures/consent.md`). Курсовые привычки работают и за пределами курса.
3. Что-то из списка уже стоит у вас с давних времён — это повод не радоваться, а проверить: знаете ли вы, когда оно срабатывает и как его выключить.
