# Имена курса — единый владелец

Источник — DESIGN-v1.md, раздел «Имена» (подтверждены заказчиком 17.09.2026). Любое имя из этой таблицы встречается в текстах курса **ровно в этом написании**. Меняется имя — меняется здесь, потом везде по ссылкам, а не наоборот.

| Что | Имя | Замечание |
|---|---|---|
| Плагин | `yunga` | kebab-case, не зарезервировано |
| Маркетплейс | `kubrik` | имя, которое ученик видит при установке |
| Установка | `/plugin install yunga@kubrik` | путь без терминала — `procedures/surface-steps.md` |
| Команды | `/yunga:<имя>` | `start`, `pomogi`, `slovo`, `pauza`, `karta`, `otkat`, `huk-proba` |
| Журнал ученика | `~/yunga-zhurnal/` | «судовой журнал»; устройство — `reference/zhurnal.md` |
| Проект ученика (если своих нет) | `~/yunga-proekt/` | заводится в сессии 1б |
| Данные плагина | `~/.claude/plugins/data/yunga-kubrik/` | только `home.json` |
| Репозиторий сборки | папка `yunga` на машине автора | путь к ней в текстах курса не упоминается |

## Этапы — только эти три названия

| Этап | Имя для ученика | Модули |
|---|---|---|
| 1 | **«Юнга»** — самостоятельность | M00–M07 |
| 2 | **«Матрос»** — инструменты | M08–M11 |
| 3 | **«Штурман»** — автоматика | M12–M15 |

Номера и `slug` модулей — `reference/module-ids.md` (там же правила их изменения).

## Как курс называет вещи ученику

Слова **«гейт», «улика», «PASS», «FAIL», «модуль M03»** — служебные, в разговоре с учеником не звучат. Ученик слышит: «готово», «не хватает вот этого — чиним вместе», «занятие про деньги». Техническое имя остаётся в файлах журнала, потому что на него ссылаются другие файлы.

Морская метафора (юнга, матрос, штурман, судовой журнал, песочница) — только в названиях. Внутри урока сравнения берутся из `reference/glossary.md` и объясняют механизм, а не украшают текст.
