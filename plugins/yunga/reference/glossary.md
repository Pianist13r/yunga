# Глоссарий (единый владелец)

Простыми словами, без жаргона. Модули объясняют термин при первом появлении и дают ссылку сюда — это справка для повторного взгляда, не текст урока. «→ M0N» — где термин вводится по-настоящему.

## Разговор с Claude

- **Сессия** — один непрерывный разговор с Claude в одной папке. Закрыл окно/вкладку — сессия закончилась; открыл заново — новая. → M00
- **Промпт** — то, что вы написали Claude: вопрос, просьба, задача.
- **Команда со слэшем** — слово с косой чертой впереди (`/status`, `/yunga:start`), набранное в поле ввода. Это не сообщение Claude, а кнопка: она сразу запускает действие. Набирать её нужно в английской раскладке и с начала строки. → M00
- **Поверхность** — то, откуда вы работаете с Claude Code: приложение на компьютере (Desktop) или чёрное окно командной строки (терминал). Один и тот же курс на разных поверхностях местами выглядит по-разному — поэтому шаги пишутся сначала для приложения, а терминал идёт веткой. → M00
- **Терминал (командная строка)** — отдельное окно, куда команды компьютеру пишут текстом, без кнопок. В приложении Claude он не нужен: курс проходится целиком без него. Встретили в уроке «если у вас есть терминал» — это необязательная ветка, её можно пропустить. → M00
- **Контекст** — всё, что Claude «помнит» прямо сейчас в этом разговоре: ваши сообщения, его ответы, прочитанные файлы. У контекста есть предел объёма — когда он заполняется, старое приходится сжимать или убирать. → M04
- **Токен** — единица, которой меряют объём текста для Claude (примерно кусочек слова). Лимиты контекста и подписки считаются в токенах, но вам обычно достаточно смотреть на проценты (`/usage`, `/context`), не на токены напрямую. → M04
- **Сжатие контекста (`/compact`)** — Claude сам ужимает историю разговора в краткий пересказ, чтобы освободить место и продолжить в той же сессии. → M04
- **Очистка контекста (`/clear`)** — стереть историю разговора полностью и начать с чистого листа в той же папке. → M04
- **Кэш промпта** — техническая штука, которая ускоряет и удешевляет ответ, если вы продолжаете разговор быстро. Если пауза слишком долгая (или вы сменили модель) — кэш «остывает», следующий ответ идёт как в первый раз. → M04
- **Модель** — «мозг», который отвечает вам (например, Fable, Opus, Sonnet, Haiku у Claude). Модели различаются по силе рассуждения и скорости. → M01
- **Effort (уровень усилия)** — насколько глубоко модель обдумывает ответ перед тем, как его дать. Выше — качественнее, но медленнее. → M01
- **`Esc`** — нажать эту клавишу, чтобы прямо сейчас остановить то, что делает Claude. → M01

## Что Claude умеет делать с вашим компьютером

- **Инструмент (tool)** — конкретное действие, которое может выполнить Claude: прочитать файл, изменить файл, выполнить команду в терминале и так далее. Каждое действие в чате — это вызов какого-то инструмента.
- **MCP-сервер** — пропуск в другое здание: Claude Code сам не умеет работать с внешним сервисом (например, MostAI), а сервер даёт ему такой пропуск с набором конкретных инструментов. Подключается один раз, дальше просто появляется в списке возможностей. → M03 (первое знакомство), M10 (подключаем сами)
- **Префикс** — общее начало имени у всех инструментов одного сервера, вроде фамилии: по нему видно, чьё это хозяйство, и по нему же пишутся правила «спроси меня» сразу на весь сервер. → M03
- **Scope** — чей это сервер (или чей агент): одной папки — файл `.mcp.json` (или файл агента) лежит прямо в ней и виден только там; мой везде — команда терминала, хранится в файле, который курс не открывает; с аккаунта — коннектор из чата, включается и выключается на сайте claude.ai. Пропуск выписан на конкретный адрес, а не на весь квартал: в другой папке он не сработает. → M10
- **Коннектор** — сервис, подключённый не файлом в папке, а с аккаунта claude.ai целиком (почта, календарь, диск и подобное): виден в любой сессии, а включается и выключается только в настройках аккаунта, не в разговоре. → M10
- **Скилл** — заготовленный набор инструкций для Claude под конкретную задачу: рецепт, который лежит в шкафу и не занимает стол, пока его не достали. Может запускаться вручную командой или самим Claude по смыслу разговора. → M08
- **Шапка-анкета (frontmatter)** — несколько строк между `---` в самом начале файла скилла: машинная часть, которую Claude читает отдельно от текста. В ней — обычно имя и описание «когда звать»; строго обязательных полей нет, но без описания Claude не поймёт, когда скилл кстати. → M08
- **Агент / субагент** — стажёр с узким поручением и своим рабочим столом: не видит вашего разговора, ваших уже прочитанных файлов и памяти — только то, что ему поручили (и ваш `CLAUDE.md`). Отчитывается перед основным Claude, а не перед вами напрямую; его «готово» — гипотеза, которую стоит проверить самому. → M11
- **Explore** — встроенный субагент Claude Code: только читает и ищет по файлам, ничего не правит и не выполняет команд. → M11
- **Бриф** — поручение помощнику (субагенту) целиком, одним сообщением: он не может переспросить по ходу, как человек, поэтому сразу — цель, зачем это нужно, ограничения, критерий готовности и полные пути. → M11
- **Хук** — правило вида «когда происходит X — автоматически сделать/спросить/запретить Y», настроенное заранее, без участия Claude в решении. → M12
- **Плагин** — набор скиллов, агентов и другого добра, который ставится целиком за одну команду (этот курс — тоже плагин).
- **Маркетплейс плагинов** — «каталог», откуда плагин устанавливается (курс лежит в маркетплейсе `kubrik`).
- **Workflow** — заранее написанный сценарий, который сам управляет несколькими агентами по шагам, без вашего участия на каждом шаге. → M13
- **Команды агентов (agent teams)** — экспериментальная возможность: несколько агентов работают и общаются друг с другом одновременно. Показывается один раз для ознакомления, не входит в обычную работу. → M13

## Права и безопасность

- **Режим разрешений** — общая настройка того, как часто Claude спрашивает разрешения перед действиями: `auto` (спрашивает пореже, для доверенных вещей — само), `default`/«ручной» (спрашивает почти всегда), `plan` (сначала только план, без действий), `bypass` (не спрашивает почти никогда — курс им не пользуется). → M02
- **Deny / ask / allow** — три уровня правила для конкретного действия: `deny` — запрещено всегда и без вопросов; `ask` — Claude спросит разрешения; `allow` — разрешено без вопроса. → M02
- **`additionalDirectories`** — список папок, которые Claude может открыть без лишних вопросов о доступе (например, ваша папка курса). → M02
- **Recently denied** — список того, что вы недавно запретили; помогает вспомнить и разрешить снова, если передумали.
- **`/doctor`** — команда, которая проверяет настройки и файлы Claude Code и предлагает исправления (сама ничего не меняет без вашего подтверждения).

## Память и документация

- **`CLAUDE.md`** — файл с вашими постоянными правилами и описанием проекта, который Claude читает в начале каждой сессии в этой папке. → M05
- **Память (авто-память)** — то, что Claude сам запоминает между разными сессиями (у каждого проекта своя папка памяти, и на другой компьютер она не переезжает) (например, «вы предпочитаете короткие ответы»), а не только внутри одного разговора. → M07
- **Капсула** — короткая заметка «на чём я остановился», которую курс сохраняет в конце каждого шага, чтобы в следующий раз не объяснять всё заново.

## Реже нужное (полный список — `reference/na-vyrost.md`)

- **`/usage`** — сколько от лимита подписки вы уже использовали.
- **`/status`** — версия Claude Code, модель, учётная запись и строка `Setting sources`: какие файлы настроек загружены в эту сессию. Режим разрешений там не показывается — он виден в селекторе рядом с полем ввода.
- **Worktree** — отдельная рабочая копия кода в git, чтобы что-то поменять, не трогая основную; в курсе не используется на маршруте.
- **Чекпоинт / `/rewind`** — откат последних изменений файлов, сделанных Claude; не откатывает то, что вы или Claude сделали через терминал.
- **Statusline (статус-строка)** — настраиваемая строка внизу окна с полезной информацией; вне маршрута курса.
- **Output style** — можно изменить манеру, в которой Claude отвечает; вне маршрута курса.
