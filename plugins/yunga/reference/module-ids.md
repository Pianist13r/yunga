**Правила изменения:** ID (`M00`–`M15`) и `slug` стабильны на весь жизненный цикл 1.x — на них ссылаются `progress.md`, `check.md`, `catalog.md`, evals. Менять название для ученика можно свободно (не техническое поле). Новый модуль — следующий свободный ID, не вставка в середину нумерации.
