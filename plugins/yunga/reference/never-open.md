# Что курс не открывает никогда

Источник — DESIGN-v1.md §5.2 (список дословный) и §5.1. Этот файл — закон для Claude на всём маршруте курса и стоп-лист для агента `course-scout` (§5.3). Он про **содержимое**: сам факт «такой файл есть» назвать можно и нужно (это часть диагностики), а вот заглядывать внутрь — нет.

## Список

| Что | Почему |
|---|---|
| `.env*` — любые (кроме `*.example`) | Обычное место для паролей и ключей |
| `*.pem`, `*.key`, `id_*`, вся папка `~/.ssh/**` | Закрытые ключи — доступ к серверам и репозиториям |
| Имена с `*credential*`, `*token*`, `*cookie*` | Название говорит само за себя |
| `~/.claude/.credentials.json` | Ключи самого Claude Code |
| `~/.claude.json` | Read отдаёт файл целиком, а там лежат MCP-серверы уровня пользователя вместе с их секретами (DC\mcp-quickstart.md:125-129) |
| `~/.mostai-mcp/.env` | Там бывает `MOSTAI_COOKIE` (§8.4) |
| Транскрипты `~/.claude/projects/**/*.jsonl`, `history.jsonl`, `sessions/`, `file-history/` | Расшифровки прошлых разговоров — личная переписка, своя и чужая |
| Профили браузеров | Пароли, куки, история |
| Внутренности `.git` | Служебное хранилище; читать там нечего, сломать можно |
| `node_modules`, `.venv` | Чужой скачанный код, тысячи файлов, нулевая польза для курса |

## Порядок работы — всегда один

1. **Glob** — получить список путей (это только имена, содержимое не читается).
2. **Фильтр имён** — выкинуть из списка всё, что попадает в таблицу выше.
3. **Read** — только то, что осталось.

Порядок именно такой, чтобы запретный файл не попал в чтение «по инерции»: сначала смотрим на список имён, потом решаем, потом открываем.

## Если секрет всё же попался в разрешённом файле

Такое бывает: ключ забыли в `CLAUDE.md`, в заметке, в примере команды. Правило одно: **называем место, не значение.**

- Так: «в `C:\Users\<имя>\moy-sayt\CLAUDE.md`, строка 42, похоже, лежит ключ — его оттуда стоит убрать».
- Не так: цитировать строку, показывать начало ключа, «замазывать» серединку — всё это уже вывод значения на экран, и он остаётся в записи сессии.

Дальше — обычный протокол: сказать, предложить убрать, правку делать по `procedures/consent.md` (копия → «да» → правка → запись в `changes.md`).

## Чего ещё курс не собирает

Имя компьютера, e-mail, содержимое авто-памяти — без отдельного «да» (§5.2). Часовой пояс в журнал записывается: он нужен для дат в `changes.md`.

## Честная граница

До того, как в M02 появятся правила `deny`, этот запрет держится **только на инструкции** — то есть на дисциплине Claude, а не на технике (§5.1). Настоящий замок ставится в M02, и именно поэтому M02 нельзя отложить дальше мини-выпуска 1.

Как проверять файлы на секреты, не выводя значения на экран, — `reference/secret-patterns.md`.
