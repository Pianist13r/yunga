# Все команды маршрута

Источник — DESIGN-v1.md §3.1 (таблица модулей), §4.5, §7.4; колонка «Desktop» — живой прогон P4 на машине автора 18.09.2026 (`RELEASE-CHECKLIST.md`).

**Держать в голове нужно ровно пять вещей:** `/yunga:start`, `/yunga:pauza`, `/yunga:pomogi`, `Esc` и `/context`. Всё остальное подскажет курс в тот момент, когда оно понадобится, — этот файл нужен, чтобы не заучивать (§3.1).

Команды набираются в английской раскладке, с косой черты — Claude Code показывает список подходящих прямо во время набора.

## Колонка «Desktop» — как читать

- **да** — проверено, работает в приложении Claude Desktop на Windows.
- **нет** — проверено, отвечает «isn't available in this environment»; в уроках такая команда не обещается.
- **не проверено** — на живой поверхности не прогонялась. Не значит «не работает»; значит «не обещаем». Предсказать по документации нельзя — это главный вывод прогона P4: правило «команда без аргументов недоступна» опровергнуто на `/status` и `/usage`.

## Команды курса

Все они начинаются с `/yunga:` — это имя плагина, чтобы они не путались с остальными.

| Команда | Одной строкой |
|---|---|
| `/yunga:start` | Единственный вход в курс: продолжить с места, где остановились. Без аргументов — меню (продолжить · карта · мини-выпуск · диагностика) |
| `/yunga:pauza` | Закончить занятие в любой момент: закладка на текущем шаге, расход лимитов, домашка. Урок дробится без потери прогресса |
| `/yunga:pomogi` | Что-то пошло не так или страшно. Разбор по симптомам — `reference/troubleshooting.md` |
| `/yunga:slovo` | «Что такое X?» — объяснение термина простыми словами; полный словарик — `reference/glossary.md` |
| `/yunga:karta` | Где я на маршруте: этапы, модули, что пройдено, что дальше |
| `/yunga:otkat` | Вернуть как было. Без аргумента — список последних изменений словами, «было → станет», и откат после «да» |
| `/yunga:huk-proba` | Учебный хук из M12: включается вручную, чтобы увидеть, как хук срабатывает. Единственный хук во всём плагине |

## Общие команды Claude Code

| Команда | Одной строкой | Модуль | Desktop |
|---|---|---|---|
| `Esc` | Клавиша. Немедленно остановить то, что Claude делает прямо сейчас | M01 | да |
| `/model` | Выбрать модель — «мозг», который отвечает. В Desktop — своё окно и меню у поля ввода | M01 | да |
| `/effort` | Насколько глубоко модель думает перед ответом | M01 | не проверено |
| `/clear` | Стереть разговор начисто и начать с нуля в той же папке | M01 | не проверено |
| `/compact` | Сжать разговор в пересказ, чтобы освободить место и продолжить | M01, M04 | не проверено |
| `/rewind` | Откатить последние правки файлов. **Не откатывает** то, что было сделано командой в терминале | M01 | да |
| `/resume` | Вернуться в один из прошлых разговоров | M01 | да |
| `/btw` | Задать вопрос «по ходу», не сбивая основную работу | M01 (справка) | не проверено |
| `/recap` | Краткий пересказ того, что уже наговорили | M01 (справка) | не проверено |
| `/context` | Чем занят контекст прямо сейчас и сколько осталось. В Desktop есть ещё кольцо у выбора модели | M04 | да |
| `/usage` | Полосы лимитов подписки. На подписке показанная сумма — **не счёт**, важны полосы | M04 | да |
| `/usage-credits` | Про доплату сверх подписки. Курс её не предлагает — упомянута, чтобы вы знали, что это | — | не проверено |
| `/status` | Версия Claude Code и какие файлы настроек загружены | M00, M02 | да |
| `/doctor` | Проверка настроек. В курсе — **только смотреть**: она сама предлагает правки, на них отвечаем «нет», а нужное делаем отдельным шагом | M02, M09 | нет |
| `/init` | Собрать черновик `CLAUDE.md` для папки. Дальше — обязательная чистка руками | M05 | да (встроенный скилл) |
| `/memory` | Посмотреть и поправить, что Claude запомнил | M07 | нет |
| `/mcp` | Список подключённых MCP-серверов и их состояние | M10 | да |
| `/hooks` | Список настроенных хуков | M12 | нет |
| `/agents` | С версии 2.1.198 только **напоминает**, что агенты задаются файлами. Смотреть — файлы в `.claude/agents/` | M11 | не проверено |
| `/add-dir` | Дать Claude доступ ещё к одной папке на эту сессию (только терминал; в Desktop доступ — настройкой) | M00 | не проверено |
| `/permissions` | Правила разрешений. В Desktop **без аргументов не работает** — правила пишутся файлом | M02 | нет |
| `/config` | Настройки. В Desktop текст после команды игнорируется; по живой проверке команда отвечает «недоступна» | — | нет |
| `/skill-doctor` | Проверка своего скилла на ошибки | M08 | не проверено |
| `/fewer-permission-prompts` | Сама читает историю сессий и дописывает разрешающие правила в настройки проекта. **Только после «да»**, до — копия файла, после — показ добавленного и строка в `changes.md` | M08 (справка) | да (встроенный скилл) |
| `/deep-research` | Долгое исследование силами нескольких помощников. Заметно расходует лимит | M13 (справка) | не проверено |
| `/workflows` | Список сценариев; там же они останавливаются и сохраняются (`s`) | M13 | не проверено |
| `/loop`, `/goal` | Повторять действие по кругу / вести к цели. Справка M13, на маршруте не обязательны | M13 (справка) | не проверено |
| `/plugin` | Установка и управление плагинами. В Desktop аргументы не разбирает — открывает экран настроек | Установка | нет (как команда) |
| `/reload-plugins` | Перечитать плагины без перезапуска (нужна версия ≥ 2.1.260) | Установка | не проверено |

## Только в терминале

Эти команды набираются не в разговоре, а в окне терминала, и в курсе всегда идут веткой «если у тебя есть терминал»:

| Команда | Зачем |
|---|---|
| `claude --version` | Узнать версию |
| `claude update` | Обновиться |
| `claude doctor` | Проверка настроек, которая годится как улика на мини-выпуске 1 |
| `claude --safe-mode` | Запуск с отключёнными расширениями — шаг разбора «не работает вообще ничего» |
| `claude mcp add` / `list` / `remove` | Подключить, посмотреть, убрать MCP-сервер (M10) |
| `claude plugin marketplace add` / `install` / `uninstall … --keep-data` | Установка и удаление курса с сохранением журнала |
| `claude plugin details`, `claude plugin validate . --strict` | Для авторов курса: вес плагина и проверка манифестов |

## Если команды нет в меню

Три обычные причины, по порядку: (1) версия Claude Code ниже нужной — `reference/versions.md`; (2) команда существует только в терминале — таблица выше; (3) она есть, но ваша поверхность её не показывает — `reference/surfaces.md`. Во всех трёх случаях курс не ломается: у каждого такого шага есть запасной путь, и `/yunga:start` пометит его в плане как недоступный.
