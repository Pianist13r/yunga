# MostAI — что можно без вопроса, что только после «да» (`money-mostai.md`)

Источник — DESIGN-v1.md §8.4, сверено с описаниями инструментов подключённого MCP-сервера MostAI (не с более новым исходником пакета, если версии разошлись — правило берёт то, что реально установлено). Единственный владелец правил MostAI в курсе — эта таблица; хук-сторож (M12, `<префикс>chat`/`<префикс>ask_second_opinion`) реализует то же самое механически, но текст объяснения ученику — отсюда.

## Корзины

| Корзина | Инструменты | Правило |
|---|---|---|
| **Без спроса** | `whoami`, `get_balance`, `spending_status`, `list_models`, `describe_model`, `estimate_price`, `list_free_generations`, `list_gallery`, `media_status` | Только смотрят — ничего не тратят и не публикуют. Claude вызывает свободно. |
| **Без спроса (с оговоркой)** | `share_link` — только форматирует ссылку на готовое, ничего не создаёт; `preview_media` — показ уже готового; `download_media` — сохраняет файл в `~/.mostai-mcp/downloads` по умолчанию (Claude называет, куда) | Тоже без вопроса, но с этим маленьким пояснением, что именно происходит. |
| **Без спроса** | `chat` с моделью по умолчанию `chatgpt-free` | Стоит 0 — Claude сообщает о вызове, но не спрашивает. |
| **Деньги** | `generate_image`, `generate_video`, `generate_audio`, `generate_media`, `edit_image`, `animate_image` | Порядок: `list_free_generations` (нет ли бесплатного варианта) → `estimate_price` → назвать модель, цену, текущий баланс → **явное «да»** (не «ну давай») → вызов → `media_status`. Одно «да» — ровно одна генерация; на вторую — новое «да». |
| **Деньги за текст** | `chat` с моделью **не** `chatgpt-free`; `ask_second_opinion` | Как выше: цена (кредиты сообщений `credits_per_message` из `list_models`/`whoami`, или ₽ — по тому, что показывает установленная версия пакета) → «да». **`ask_second_opinion` с любыми `files`** — отдельное «да»: файлы уходят на сервер MostAI, это стоит сказать прямо, даже если сама модель бесплатная. |
| **Публично** | `like_media`, `publish_media` | «Да» с названием объекта — результат увидят другие люди от имени ученика. |
| **Необратимо** | `delete_media` | «Да» с названием объекта и явным «вернуть нельзя». |
| **Пополнение** | `topup` | Без вопроса, но **только когда ученик сам спросил**, как пополнить счёт: выдать ссылку и текущий баланс. Сам не списывает — платит человек на сайте. Курс никогда не предлагает пополнение первым и не трогает платёжные данные. |
| **Нет в этой таблице** | Любой новый или незнакомый инструмент MostAI | Всегда «да», пока модуль не разобрал его описание и правило не появилось здесь. |

## Модели в примерах курса

Курс никогда не называет и не советует GLM, Kimi, DeepSeek, Qwen и связанные с ними модели — ни в объяснении `list_models`/`estimate_price`, ни в готовых вставках. Выбор ученика в сторону этих моделей курс не продвигает и не записывает в эталоны.

## Слой M03 (модуль «MostAI безопасно»)

1. Сверить список инструментов из `/mcp` (или Connectors) с этой таблицей.
2. Добавить ask-правила с префиксом сервера (из `profile.md` ученика) на денежные, публичные, необратимые и незнакомые инструменты — по протоколу `consent.md`. В именах денежных правил допустим глоб (`<префикс>generate_*`) — так под правило попадают и будущие генераторы.
3. **`chat` отдельным правилом не закрыть до конца:** MCP-правило разрешений называет сервер или инструмент целиком, а параметр вызова (какая именно модель) правилами разрешений не фильтруется — значит платную модель через `chat` ловит только хук-сторож (M12), а до него — честное обещание Claude в разговоре (этап 1).
4. **Проверка «замок работает» без риска реального списания:** если у сервера настроен `MOSTAI_WARN_PRICE` (> 0), вызов `generate_*` на модели с ценой не ниже этого порога **без `confirm`** — сервер вернёт `needs_confirmation`, не спишет ничего. Ученику сказать заранее: «даже согласие сейчас ничего не спишет — жми No для интереса». Если порог не задан или цена ниже — вызов уйдёт в бесплатный список (`list_free_generations`), проверка не покажет предупреждения — это нормально, не ошибка.

## Опция M03 (по желанию) — серверные ограничители

Настраиваются в окружении процесса сервера MostAI (не Claude Code): `MOSTAI_MIN_BALANCE` — порог «мало денег»; `MOSTAI_WARN_PRICE` — генерация дороже этого порога возвращает `needs_confirmation` без списания; `MOSTAI_MAX_PRICE` — жёсткий потолок цены (по умолчанию не задан); `MOSTAI_WARN_CHAT_RUB` — порог подтверждения для платных текстовых моделей в `ask_second_opinion`.

**Честная граница, сказать ученику прямо:** `max_price` в самом вызове `generate_*` **заменяет** `MOSTAI_MAX_PRICE` на этот один вызов — потолок в `.env` не защищает от модели, которая сама передаст другое значение. Он страхует только от случайной дорогой генерации, а не от намеренного обхода. Настоящая гарантия против конкретной платной модели — ask-правило (шаг 2 выше), не потолок.

**Как поставить (если ученик решил).** Значения читаются из `~/.mostai-mcp/.env` (или из окружения процесса сервера) при старте и не перезаписывают уже заданные переменные. В этом файле бывает `MOSTAI_COOKIE` — Claude файл **не читает**. Порядок по `consent.md`: (1) копия файла командой ОС; (2) Claude даёт одну готовую строку с путём и суммой, ученик добавляет её сам (или Claude — после «да», не открывая остальное содержимое); (3) перезапуск сервера — новая сессия (CLI) или полное закрытие Desktop; (4) проверка — `spending_status`. Не изменилось — откат из копии, запись в журнал, без «домашки»: ask-слой из шага 2 работает и без этой опции.

## Что делает курс, если инструмент платит, а денег нет

Никогда не предлагает пополнение сам (см. корзину «Пополнение» выше). Показывает бесплатную альтернативу (`list_free_generations`) или откладывает шаг.
