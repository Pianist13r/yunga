# M00 — задание проверяющему (служебный файл)

Читает `agents/course-checker.md`. Курс вызывает его с **одним** разделом — тем, чей шаг закрывается, — и подставляет вместо `<журнал>` полный путь к папке журнала ученика. Отчёт служебный: ученику из него пересказывается только суть.

**Общая оговорка ко всем разделам:** улики этого модуля — файлы **внутри журнала ученика**, и абсолютные пути с именем его учётной записи в них **ожидаемы** (опись копии без полного пути бесполезна). Проверка «личные пути» здесь означает только одно: путь не должен вести за пределы журнала, домашней папки ученика и папок его проектов, перечисленных в `profile.md` (они могут лежать на другом диске). Проверка «секреты» работает как обычно — значения ключей в журнале не место.

## Шаг 1

- **улика:** `<журнал>/progress.md`
- **критерии:**
  1. первая строка — `---`, шапка закрыта второй `---`;
  2. в шапке есть все поля: `schema`, `plugin_version`, `surface`, `os`, `tz`, `stage`, `current` (с `module` и `step`), `last_seen`, `проходил`; `claude_version` может отсутствовать — он появляется после первого осмотра;
  3. `schema: 1`;
  4. поля `surface`, `os`, `tz`, `current` заполнены значениями, а не заглушками из заготовки (текст в квадратных скобках, `TODO`, `<...>`, `xxx`). Поля `claude_version` и `last_seen` на этом шаге могут остаться незаполненными: первое появляется после осмотра системы, второе — при закрытии встречи через `pauza`;
  5. `surface` — `desktop` или `cli`; `os` — `windows`, `macos` или `linux`; `проходил` — `ученик` или `автор`;
  6. в теле есть таблица модулей со столбцами «Модуль · Статус · Улика · Дата», и статусы — только из пяти: `не начат`, `идёт`, `пройден`, `отложен`, `недоступно (версия ниже N)`.
- **бюджет:** файл не больше 6 КБ; шапка не больше 20 строк.

## Шаг 2

- **улика:** `<журнал>/backups/` — папка вида `ГГГГ-ММ-ДД_start`, в ней `manifest.md`
- **критерии:**
  1. папка названа `<дата>_start`, дата в формате `ГГГГ-ММ-ДД`;
  2. рядом с `manifest.md` лежат сами скопированные файлы — не меньше одного;
  3. в `manifest.md` есть дата со временем **и часовым поясом**;
  4. таблица описи — ровно четыре столбца: «Файл · Откуда · Байт · sha256»; в каждой строке заполнены все четыре;
  5. «Откуда» — полный путь к оригиналу (не `~`, не относительный): по нему возвращают файл назад;
  6. каждому файлу в папке соответствует строка описи, лишних строк нет;
  7. в `<журнал>/journal/` есть файл занятия за эту дату, и в нём названо, что копия снята и где лежит. **Строки `CH-NNN` в `changes.md` здесь быть не должно:** туда пишутся правки вне журнала, а на этом шаге ничего не менялось — копия легла внутрь журнала.
- **бюджет:** `manifest.md` не больше 40 строк.
- **дополнительно:** в `manifest.md` и в файле занятия не должно быть содержимого скопированных файлов — только имена, размеры и суммы. Похоже на значение ключа или токена — это находка, назвать место без значения.

## Шаг 3

- **улика:** `<журнал>/profile.md`, `<журнал>/plan.md`, `<журнал>/changes.md`
- **критерии:**
  1. `profile.md` — есть список проектов ученика: у каждого название словами и полный путь;
  2. `profile.md` — есть разделы «сильные стороны» и «риски», оба непустые;
  3. `plan.md` — заполнены ближайшие шаги (по контракту их три, а не весь курс), в том порядке, который утвердил ученик; заглушек из заготовки не осталось;
  4. `changes.md` — есть строка `CH-001` про добавление папок в настройки: это первая правка вне журнала за курс. В строке восемь полей по формату заготовки: номер, дата с поясом, файл, что изменено, зачем, путь к бэкапу, как откатить, как проверено;
  5. папка копии, названная в `CH-001`, существует, содержит `manifest.md` и не совпадает с папкой копии из шага 2;
  6. в файле занятия за эту дату записана базовая линия настроек — строка `Setting sources` из `/status`.
- **бюджет:** `profile.md` не больше 4 КБ.
- **неясно (не угадывать):** проектов у ученика может не быть вовсе — тогда в `profile.md` вместо списка стоит запись про учебный проект `yunga-proekt`, и это не нехватка. Пункт 1 в таком случае считается пройденным, если такая запись есть; нет ни того, ни другого — это `НЕЯСНО` с вопросом, а не `FAIL`.
