# Мини-выпуск 2 — задание проверяющему (служебный файл)

Читает `agents/course-checker.md`. Курс вызывает его **один раз**, целиком этим файлом, и подставляет полные пути вместо `<журнал>` (папка журнала ученика), `<проект>` (рабочая папка сквозной задачи или `~/yunga-proekt/`), `<песочница>` (`<журнал>/pesochnica/`), `<скиллы>` (`~/.claude/skills/`) и `<агенты>` (`~/.claude/agents/`); путь до писателя (`<журнал>/.claude/agents/`) пишется полностью, не сокращается через `<журнал>`.

**Оговорки.**
1. Проверяющий **только читает**: команд не запускает, настроек не правит, ничего не чинит. Срабатывания (ответ на «какие помощники доступны», строка вызова с именем сервера, «connected» в `/mcp`, итог `/wrap`) подтверждает курс, а не он.
2. Абсолютные пути с именем учётной записи ученика **ожидаемы**. Находка — путь за пределы `<журнал>`, `<проект>`, `<песочница>`, `<скиллы>` и `<агенты>`.
3. Значения ключей, токенов, cookie и балансов **не цитировать** — ни целиком, ни фрагментом: только называть место.
4. Файлы `~/.claude.json` и `~/.claude/.credentials.json` не открывать никогда, даже если на них ссылается правило.
5. Отчёт служебный: `PASS` / `FAIL` / `НЕЯСНО` с `путь:строка`. Ученику из него пересказывается только суть — «готово» или «не хватает: X».
6. **Отложенный модуль снимает свою проверку, а не проваливает её.** M09 отложен → раздел 2 (`/wrap`) целиком `НЕЯСНО`, критерии не применяются. M10 отложен → раздел 3 (MCP-сервер) целиком `НЕЯСНО`. M11 отложен → раздел 4 (агенты) целиком `НЕЯСНО`. Статус модуля проверяющий берёт из таблицы «Пройденное» в `<журнал>/progress.md` (статус «отложен») — это ожидаемый результат, а не находка проверяющего.
7. **Файлы настроек — только `count`/`-o`.** `*/.claude/settings*.json` внутри `<журнал>` и `<песочница>` — только `Grep` в режиме `count` или `-o` по имени ключа (`reference/secret-patterns.md`); целиком `Read` не открывать, значения не цитировать. `<песочница>/.mcp.json` (учебный или свой сервер ученика) открывать `Read` целиком можно, только если `Grep -c '"(headers|env)"'` по нему дал 0; иначе файл целиком не читать, а по номеру строки из `Grep -n -o` писать `НЕЯСНО`: «в `.mcp.json` есть `headers`/`env` — сверить с учеником, значения не читались».

## 1. Свой скилл на месте

- **улика:** `<скиллы>/<имя скилла ученика>/SKILL.md`, `<журнал>/SOURCES.md`
- **критерии:**
  1. файл скилла существует; открывающий `---` — первая строка, есть отдельная строка с закрывающим `---`; YAML между ними разбирается; поле `description` заполнено, без `[впиши`; поле `name`, если оно есть, заполнено без `[впиши` (само поле у скилла не обязательно — команду задаёт имя папки, а не оно);
  2. `<журнал>/SOURCES.md` существует, не пуст и содержит хотя бы одну заполненную строку про скилл из критерия 1, без `[впиши…]`;
  3. если по названию, `description` или телу скилла видно, что он правит файлы, отправляет что-то наружу или делает необратимое действие, — в шапке есть поле `disable-model-invocation` со значением `true` (документация с 2.1.218 принимает и `yes`/`on`/`1` как то же самое — не находка, но предложить `true` для единообразия); опечатка в имени самого поля (`disable-model-invokation` и подобные) — отдельная находка.
- **бюджет:** —
- **неясно (не угадывать):** скилл, заведённый до курса и разобранный на M08 («у тебя уже есть X»), без строки `CH-NNN` про создание — не находка; такой скилл без поля `name` — тоже не находка (имя берётся из папки); спорный случай («немного правит, немного объясняет») по критерию 3 — `НЕЯСНО`, а не `FAIL`.

## 2. Ритуал `/wrap` не потерял защиту

- **улика:** `<скиллы>/wrap/SKILL.md` (или файл под другим именем, если ученик формализовал свой прежний ритуал — имя берётся из строки `CH-NNN` M09 s1)
- **критерии:**
  1. файл существует; `---` первой строкой и отдельной закрывающей строкой; YAML между ними разбирается;
  2. поле `disable-model-invocation` присутствует со значением `true` (`yes`/`on`/`1` — то же самое по документации, не находка, но предложить `true`; опечатка в имени самого поля — находка) — за прошедшие с M09 модули его никто не мог тихо снять, вызывать ритуал по-прежнему должен только ученик;
  3. в шапке и в теле нет `[впиши`, в шапке нет `context: fork`.
- **бюджет:** файл — не больше 100 строк.
- **неясно:** см. оговорку 6 — если M09 отложен, раздел не проверяется.

## 3. MCP-сервер: на месте или честно убран

- **улика:** `<песочница>/.mcp.json` (если он есть), `<песочница>/.claude/settings.local.json` (если файл существует), `<журнал>/passport.md`, `<журнал>/changes.md`
- **перед чтением:** `Grep -c '"(headers|env)"'` по `<песочница>/.mcp.json` (оговорка 7) — результат 0, файл можно прочитать целиком обычным `Read`; результат не 0 — файл целиком не читать, отметить находку по номеру строки из `Grep -n -o`, значения не цитировать.
- **критерии:**
  1. **если сервер учебный и не убран:** `.mcp.json` разбирается как JSON; в `mcpServers` — ровно одна запись `claude-code-docs`; `type` равен `http` буква в букву; `url` равен `https://code.claude.com/docs/mcp` буква в букву; нет полей `headers`, `env`, `command`, `args`; файл не длиннее 15 строк;
  2. если `<песочница>/.claude/settings.local.json` существует — `Grep -c '"enableAllProjectMcpServers"\s*:\s*true'` по этому файлу равен 0; отличное от 0 значение — находка;
  3. **если сервер убран:** файла `<песочница>/.mcp.json` больше нет; в `<журнал>/changes.md` есть строка `CH-NNN` про перенос в `<журнал>/Архив/…`, и `Glob '<журнал>/Архив/*/.mcp.json'` находит перенесённый файл; строка в `passport.md` помечена «убран, дата», а не стёрта;
  4. в `passport.md` есть строка про `claude-code-docs` со всеми четырьмя частями — что стоит, где (со scope), зачем, как выключить, — без `[впиши…]`; если у ученика есть MostAI — такая же строка про него.
- **бюджет:** `.mcp.json` — 15 строк.
- **неясно:** см. оговорку 6 — если M10 отложен, раздел не проверяется; если сервер убран ещё на M10 s3 и у ученика нет MostAI — критерии 1–2 не применяются (проверка снята по той же причине, что при отложенном M10; в файле занятия должна быть строка «MCP — сервер убран на M10, проверка снята»), критерии 3–4 применяются как обычно; свой сервер ученика вместо учебного («у тебя уже есть X») — критерии 1 и 2 к `claude-code-docs` не применяются: `НЕЯСНО` с вопросом «где он стоит и есть ли строка в паспорте», не находка, если в файле занятия записан вызов с его именем; критерий 2 применяется, только если `<песочница>/.claude/settings.local.json` существует.

## 4. Оба агента — в границах своих полномочий

- **улика:** `<агенты>/razvedchik.md` (или имя из `CH-NNN` M11 s2), `<журнал>/.claude/agents/pisatel.md`, `<журнал>/passport.md`
- **критерии:**
  1. у обоих файлов: `---` первой строкой и отдельной закрывающей строкой; YAML между ними разбирается; поля `name` и `description` есть; `name` совпадает с именем файла без `.md`; `description` **начинается** с условий вызова — у `pisatel.md` со слов «Только по прямой просьбе»; имена полей шапки — буква в букву, составные — camelCase (`maxTurns`, `disallowedTools`); незнакомое имя поля — отдельная находка: Claude Code его молча игнорирует, не сообщая об ошибке; `model` — одно из `haiku`, `sonnet`, `opus`, `fable`, `inherit` или полный ID модели Claude; полей `permissionMode`, `mcpServers`, `hooks` нет;
  2. `razvedchik.md`: поле `tools` есть, и **каждый** его элемент — из набора `Read`, `Glob`, `Grep`; любой другой инструмент в списке (`Edit`, `Write`, `Bash`, `PowerShell` и подобные) — находка;
  3. `pisatel.md`: `tools` содержит `Read`, `Edit`, `Write` и **не** содержит `Bash`, `PowerShell`, `NotebookEdit`, `WebFetch`, `WebSearch`, `Agent`;
  4. `passport.md` содержит два блока — про `razvedchik` и про `pisatel` — в каждом заполнены все пять вопросов, без `[впиши…]`; «как выключить» в обоих — перенос файла агента в `Архив/`.
- **бюджет:** файл агента — 80 строк.
- **неясно:** см. оговорку 6 — если M11 отложен, раздел не проверяется; свой агент ученика до курса с полями сверх списка — `НЕЯСНО` с вопросом «оставляем сознательно?», не `FAIL`.

## 5. Журнал сходится и веха датирована

- **улика:** `<журнал>/progress.md`, `<журнал>/changes.md`, `<журнал>/passport.md`
- **критерии:**
  1. `progress.md` разбирается: шапка целая, `schema: 1`, обязательные поля заполнены, заглушек нет; в таблице «Пройденное» — `M08` в статусе `пройден`, а `M09`–`M11` каждый в статусе `пройден` или `отложен` — иное сочетание находка: выпуск засчитывать нельзя;
  2. в разделе «Вехи» строка «Мини-выпуск 2» — с датой и часовым поясом (если выпуск засчитан);
  3. каждая строка `CH-NNN`, на которую ссылаются разделы 1–4 этого файла, действительно есть в `<журнал>/changes.md` и называет одно из трёх: (а) путь к живой копии в `backups/`, и эта папка существует и содержит `manifest.md`; (б) для нового файла — пометку «файла не было» в графе «путь к бэкапу»; (в) для переноса в `Архив/` (учебный `.mcp.json`, или файл агента, если его выключали) — путь в `<журнал>/Архив/…`, по которому `Glob` находит перенесённый файл. Строка без любого из трёх — находка: откат по ней невозможен;
  4. в `passport.md` строка «Дата последнего обслуживания» заполнена датой с часовым поясом, не раньше даты выпуска, без `[впиши`.
- **бюджет:** —
- **неясно:** строка отложенного модуля стоит в таблице «Пройденное» со статусом «отложен» — это ожидаемо, не находка.

## 6. Приватность и границы курса

- **улика:** `<журнал>` целиком, кроме `backups/`
- **критерии:**
  1. в журнале нет значений, похожих на ключи, токены, пароли и cookie (шаблоны — `reference/secret-patterns.md`; файлы `*/.claude/settings*.json` внутри `<журнал>` — читать только режимом `count`/`-o`, оговорка 7, целиком не открывать); нашлось — назвать место, **не цитируя значение**;
  2. в журнале нет платёжных данных и следов предложения пополнить счёт — курс этого не делает никогда;
  3. в `<песочница>` нет файлов из настоящих проектов ученика — только учебные, созданные курсом (в том числе `pisatel-do/` и `pisatel/`, если M11 не отложен);
  4. нигде не записано, что курс что-то удалил: «убрать» в курсе всегда означает перенос в `Архив/`.
- **бюджет:** —
