# M10 — задание проверяющему (служебный файл)

Читает `agents/course-checker.md`. Курс вызывает его с **одним** разделом и подставляет полные пути вместо `<журнал>` (папка журнала ученика), `<песочница>` (`<журнал>/pesochnica/`) и `<настройки>` (файл настроек пользователя, `~/.claude/settings.json`).

**Оговорки ко всем разделам.**
1. Абсолютные пути с именем учётной записи ученика — ожидаемы, это не находка. Находка — путь за пределами `<журнал>`, `<песочница>` и `<настройки>`.
2. Наблюдаемое срабатывание (вызов сервера с его именем в строке ответа, экран одобрения, «connected» в `/mcp`) файлом не проверяется — это подтверждает курс в моменте. Отсутствие такой записи в отчёте не пишется.
3. `settings.local.json` и `<настройки>` — файлы настроек: проверять только режимом `count` или `-o`, целиком не читать и значения не цитировать (`reference/secret-patterns.md`).
4. `~/.claude.json` не открывается никогда и как улика не используется ни в одном разделе.
5. Свой MCP-сервер ученика, стоявший до курса («у тебя уже есть X»), вместо учебного — не находка сама по себе, если запись о вызове с его именем видна в файле занятия. В этом случае критерии 1–8 шага 2 — `НЕЯСНО`, а не `FAIL`: сервер `claude-code-docs` мог стоять у ученика заранее и на другом scope (официальная установка ставит его под тем же именем) — тогда в шаге 3 ожидаемый ответ игры меняется на «будет, но это мой, а не песочницы», и это не находка.

## Шаг 1

- **улика:** `<журнал>/journal/` — файл занятия за дату шага
- **критерии:**
  1. в файле перечислены серверы из `/mcp` этой сессии, и по каждому назван ответ «чей»: этой папки / не из этой папки (мой везде, плагин или не ясно) / с аккаунта — либо явно записано «пусто», если список был пуст;
  2. отдельно упомянуты Connectors — список или «пусто»;
  3. если в записи фигурирует MostAI — есть сверка префикса с `mostai_prefix` из `profile.md` (совпадает или нет — оба варианта допустимы, важно, что сверка сделана);
  4. в записи нет значений ключей, токенов и адресов с параметрами авторизации — только имена серверов.
- **бюджет:** файл занятия не больше 3 КБ.
- **неясно (не угадывать):** если у ученика нет MostAI — пункт 3 неприменим, это не находка.

## Шаг 2

- **улика:** `<песочница>/.mcp.json`, `<журнал>/changes.md`, `<песочница>/.claude/settings.local.json` (если файл существует)
- **перед чтением:** `Grep -c '"(headers|env)"'` по `<песочница>/.mcp.json`: результат 0 — файл можно прочитать целиком обычным `Read` (в нём только имя сервера, `type`, `url`); результат не 0 — файл целиком не читать, отметить находку по критерию 5 номером строки из `Grep -n -o`, значения не цитировать.
- **критерии:**
  1. `<песочница>/.mcp.json` разбирается как JSON;
  2. в `mcpServers` — **ровно одна** запись, ключ `claude-code-docs`;
  3. у неё поле `type` равно `http` буква в букву;
  4. поле `url` равно `https://code.claude.com/docs/mcp` буква в букву;
  5. в записи нет полей `headers`, `env`, `command`, `args`;
  6. файл не длиннее 15 строк;
  7. в `<журнал>/changes.md` есть строка `CH-NNN` про этот файл: для нового файла — «путь к бэкапу» = «файла не было», «как откатить» = «перенести файл в `Архив/`»;
  8. если `<песочница>/.claude/settings.local.json` существует — `Grep -c '"enableAllProjectMcpServers"\s*:\s*true'` по этому файлу равен 0; отличное от 0 значение — находка;
  9. если ученик поставил ask-правило на `submit_feedback` (в `s2` или `s3`): `Grep -c '"mcp__claude-code-docs__submit_feedback"'` по `<настройки>` ≥ 1 и `Grep -c 'mcp__claude-code-docs__submit_feedback\('` по нему же = 0; файл целиком не читать, значения не цитировать;
  10. в файле занятия — предсказание игры «от сервера или из памяти» записано **до** перехода в песочницу, а итог (подпись `claude-code-docs` видели / не видели) дописан после возвращения.
- **бюджет:** `.mcp.json` — 15 строк.
- **неясно:** если файла занятия за этот шаг нет — критерий 10 не выполнен, это `НЕЯСНО` про игру, а не `FAIL` по самому серверу: файл `.mcp.json` и `CH-NNN` (критерии 1–9) проверяются отдельно и объективно.

## Шаг 3

- **улика:** `<журнал>/passport.md`, `<журнал>/journal/` — файл занятия за дату шага; если сервер убран — также `<журнал>/changes.md`, `<журнал>/Архив/`, `<песочница>/.mcp.json`
- **критерии:**
  1. в `passport.md` есть строка (или блок короткой формы) про `claude-code-docs` с четырьмя частями: что стоит, где (называет `pesochnica` или её полный путь), зачем, как выключить — все четыре заполнены, без `[впиши…]`;
  2. в «где» так или иначе упомянут scope — что сервер виден только в этой папке (словом «scope», «одна папка», «проект» или похожим по смыслу — дословного совпадения не требуется);
  3. в файле занятия — предсказание про scope, записанное **до** проверки `/mcp` в сессии журнала;
  4. **если сервер убран:** в `<журнал>/changes.md` — строка `CH-NNN` на перенос `.mcp.json` в `<журнал>/Архив/…`; `Glob '<журнал>/Архив/*/.mcp.json'` находит файл; файла `<песочница>/.mcp.json` больше нет; строка в `passport.md` помечена как «убран» (с датой), а не стёрта;
  5. **если сервер оставлен:** пунктов 4 нет, и это не находка — отсутствие переноса при выборе «оставить» ожидаемо.
- **бюджет:** файл занятия — не больше 3 КБ.
- **неясно (не угадывать):** формулировка строки паспорта может отличаться от образца `s3.md` дословно — это не находка, если все четыре части на месте и по смыслу верны.
