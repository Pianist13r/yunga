# M08 — задание проверяющему (служебный файл)

Читает `agents/course-checker.md`. Курс вызывает его с **одним** разделом и подставляет полные пути вместо `<журнал>` (папка журнала ученика), `<проект>` (рабочая папка ученика) и `<скиллы>` (`~/.claude/skills/`); `<имя>` — имя папки скилла ученика из `s2` (курс подставляет его из строки `CH-NNN` шага 2 в `changes.md`).

**Оговорки ко всем разделам.**
1. Абсолютные пути с именем учётной записи ученика — ожидаемы, это не находка. Находка — путь за пределами `<журнал>`, `<проект>` и `<скиллы>`.
2. Наблюдаемое срабатывание скилла (на команду или на фразу) файлом не проверяется — это подтверждает курс в моменте. Отсутствие такой записи в отчёте не пишется.
3. Содержимое скилла ученика может касаться его личных дел — цитировать текст `description` и тела скилла можно (это не секрет), но не содержимое файлов, которые скилл сам читает или создаёт по сквозной задаче.
4. Скилл, заведённый до курса («у тебя уже есть X») — без строки `CH-NNN` про его создание это не находка; критерии по формату применяются к тому, что есть, а не к истории его появления.

## Шаг 1

- **улика:** `<журнал>/journal/` — файл занятия за дату шага
- **критерии:**
  1. в файле названы полные пути к `skills/slovo/SKILL.md` и `skills/karta/SKILL.md` установленного плагина;
  2. по каждому из двух назван правильный ответ на «кто зовёт»: `slovo` — ученик командой **и** Claude сам (в шапке нет `disable-model-invocation`); `karta` — только ученик командой (в шапке есть `disable-model-invocation: true`); перепутанный ответ — находка;
  3. записи о правке файлов `slovo`/`karta` или о создании скилла ученика нет — на этом шаге их быть не должно (совпадение даты с шагом 2, если встреча одна, — само по себе не находка, смотрим на содержание строки, а не только на дату).
- **бюджет:** файл занятия не больше 3 КБ.
- **неясно (не угадывать):** если вместо `slovo`/`karta` разобран свой скилл ученика («у тебя уже есть X») или `mostai` — это не находка, критерии 1–2 применяются к тому, что разобрано на самом деле.

## Шаг 2

- **улика:** файл `SKILL.md` внутри `<скиллы>/<имя>/`, `<журнал>/changes.md` (папка копии в `<журнал>/backups/` — только если файл существовал и правился)
- **критерии:**
  1. файл существует; открывающий `---` — первая строка файла, есть отдельная строка с закрывающим `---`; между ними — YAML, который разбирается; есть поля `name` и `description`;
  2. поле `description` не пустое и **начинается** с условий вызова («когда звать»), а не сразу с описания действия;
  3. каждое имя поля в шапке — из списка документации, буква в букву, с дефисами (`name`, `description`, `disable-model-invocation`, …); незнакомое имя поля (например, `descripton` или `disable-model-invokation`) — находка, а не молчаливая опечатка;
  4. если название или содержание скилла предполагает, что он правит файлы, отправляет что-то или делает необратимое действие, — в шапке есть строка `disable-model-invocation: true`, написанная буква в букву (по критерию 3);
  5. нет строк `` !`команда` ``, нет поля `allowed-tools`, нет `context: fork`;
  6. нет секретов и абсолютных личных путей за пределами `<журнал>`, `<проект>` и `<скиллы>` (оговорка 1);
  7. файл не длиннее ориентира «на экран» (жёсткий порог — 500 строк, дальше это уже находка сама по себе);
  8. в `<журнал>/changes.md` есть строка `CH-NNN` про создание этого файла (кроме случая «у тебя уже есть X» — оговорка 4); для нового файла папки копии в `backups/` нет (копировать было нечего — `procedures/backup-rollback.md`), в графе «путь к бэкапу» — «файла не было», в графе «как откатить» — «перенести файл в `Архив/`» (курс ничего не удаляет); если файл существовал и правился — папка копии с `manifest.md` есть.
- **бюджет:** файл скилла — 500 строк (жёсткий порог), ориентир курса — до 120 строк.
- **неясно:** скилл без побочных действий (только объясняет или показывает) и без `disable-model-invocation` — это ожидаемо, а не находка; спорный случай («немного правит, немного объясняет») помечается `НЕЯСНО`, а не `FAIL`; скилл, заведённый до курса, с полем `allowed-tools` или строкой `` !`команда` `` — тоже `НЕЯСНО` с вопросом «оставляем сознательно?», а не `FAIL`.

## Шаг 3

- **улика:** `<журнал>/SOURCES.md` (файл мог появиться раньше под именем `sources.md` — принимается любое написание регистра)
- **критерии:**
  1. файл существует и по структуре повторяет заготовку (`templates/zhurnal/SOURCES.md`) — есть таблица или блоки с полями «имя (команда)», «откуда», «дата», «что поменял», «как выключить»;
  2. есть хотя бы одна заполненная строка про скилл из `s2` — совпадает по имени с файлом `<скиллы>/<имя>/SKILL.md` из шага 2, и в ней не осталось плейсхолдеров `[впиши…]`;
  3. поле «откуда» в этой строке заполнено одним из трёх видов, а не пересказом свободным текстом произвольной длины: «сам», «взят из …», «из заготовки курса».
- **бюджет:** файл — не больше 40 строк.
- **оговорка:** наблюдаемое срабатывание (проверка на фразу или на команду) файлом не проверяется — см. оговорку 2 в шапке этого файла.
- **неясно (не угадывать):** формат `SOURCES.md` — решение курса, не стандарт документации; строка, отличающаяся от заготовки по формулировке, но сохраняющая все пять полей по смыслу, — не находка.
