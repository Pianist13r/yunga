# Мини-выпуск 1 — задание проверяющему (служебный файл)

Читает `agents/course-checker.md`. Курс вызывает его **один раз**, целиком этим файлом, и подставляет полные пути вместо `<журнал>` (папка журнала ученика), `<настройки>` (`~/.claude/settings.json`) и `<CLAUDE.md>` (ядро правил ученика в домашней папке).

**Оговорки.**
1. Проверяющий **только читает**: команд не запускает, настроек не правит, ничего не чинит. Срабатывания (отказ, запрос разрешения) подтверждает курс, а не он.
2. Абсолютные пути с именем учётной записи ученика **ожидаемы**. Находка — путь за пределы журнала, домашней папки и папок, которые ученик назвал своими.
3. Значения ключей, токенов, cookie и балансов **не цитировать** — ни целиком, ни фрагментом: только называть место.
4. Файлы `~/.claude.json` и `~/.claude/.credentials.json` не открывать никогда, даже если на них ссылается правило.
5. Отчёт служебный: `PASS` / `FAIL` / `НЕЯСНО` с `путь:строка`. Ученику из него пересказывается только суть — «готово» или «не хватает: X».

## 1. Настройки разбираются и правила на месте

- **улика:** `<настройки>`
- **критерии:**
  1. файл разбирается как JSON — скобки, запятые, кавычки. Невалидный файл — главная находка выпуска: такие настройки Claude Code при старте не примет целиком, и оба замка окажутся выключены;
  2. ни одна строка правил не выглядит отброшенной: в `permissions.deny` и `permissions.ask` нет пустых строк, обрывков без закрывающей скобки и правил с параметром внутри имени MCP-инструмента (`mcp__сервер__инструмент(что-то)`) — такие правила не работают;
  3. в `permissions.deny` — семь строк запрета на секреты из M02, пути к файлам начинаются с `//`;
  4. в `permissions.ask` — пара правил на действие наружу (оба способа выполнять команды) из M02 **и** правила на платные, публичные и необратимые вызовы сервиса из M03 с настоящим префиксом (`mcp__<имя-сервера>__…`, не шаблонный `<префикс>`);
  5. сервиса у ученика нет — вместо правил M03 засчитывается вторая пара правил на действие наружу; смотреть, что об этом сказано в `<журнал>/journal/`.
- **бюджет:** —
- **неясно (не угадывать):** свои правила ученика, стоявшие до курса, — не находка. Проверяется наличие наших и отсутствие их дублей в `permissions.allow`.

## 2. Документы работают

- **улика:** `<CLAUDE.md>`, карта ученика, `<журнал>/decisions.md`
- **критерии:**
  1. `<CLAUDE.md>` короче 200 строк (длинная памятка соблюдается хуже — об этом шаг M05);
  2. в нём есть хотя бы три правила поведения, и они не пересказывают то, что видно в папках ученика (перечни файлов, структура проекта) — такой пересказ находка, а не нехватка;
  3. карта содержит строку «сверено с диском ДАТА», дата не старше даты M06;
  4. каждый путь из карты существует на диске (проверяется `Glob` по пути, без чтения содержимого);
  5. в `decisions.md` есть минимум две строки — по одной хотя бы из M06 и M07 — каждая с причиной («почему так»).
- **бюджет:** `<CLAUDE.md>` — до 200 строк.

## 3. Журнал ведётся и его можно отмотать назад

- **улика:** `<журнал>/progress.md`, `<журнал>/changes.md`, `<журнал>/capsule.md`, `<журнал>/passport.md`, `<журнал>/backups/`
- **критерии:**
  1. `progress.md` разбирается: шапка целая, `schema: 1`, все обязательные поля заполнены, заглушек нет;
  2. в таблице гейтов модули `M00`–`M07` имеют один из пяти допустимых статусов, и `M02`, `M03` — `пройден` (иначе выпуск засчитывать нельзя);
  3. в разделе вех отмечена веха «деньги под замком» с датой и часовым поясом;
  4. каждая строка `CH-NNN` в `changes.md` называет путь к копии, и эта папка существует и содержит `manifest.md`; строка без живой копии — находка: откат по ней невозможен;
  5. `capsule.md` — не больше 2 КБ и по шаблону: есть раздел «СЛЕДУЮЩИЙ ШАГ»;
  6. `passport.md` — не больше 15 строк, в каждой строке видно четыре вещи: что стоит, где, зачем, как выключить. Строка без «как выключить» — находка: паспорт нужен ровно для этого.
- **бюджет:** `passport.md` — 15 строк, `capsule.md` — 2 КБ.
- **неясно:** ученик мог пройти модуль в режиме «у тебя уже есть X» — тогда `CH-NNN` на него может не быть, а улика лежит в файле занятия. Это `НЕЯСНО` с вопросом, а не `FAIL`.

## 4. Приватность и границы курса

- **улика:** `<журнал>` целиком, кроме `backups/`
- **критерии:**
  1. в журнале нет значений, похожих на ключи, токены, пароли и cookie (шаблоны — `reference/secret-patterns.md`); нашлось — назвать место, **не цитируя значение**;
  2. в журнале нет платёжных данных и следов предложения пополнить счёт — курс этого не делает никогда;
  3. в `pesochnica/` нет файлов из реальных проектов ученика — там только учебные, созданные курсом;
  4. нигде не записано, что курс что-то удалил: «убрать» в курсе означает перенос в `Архив/`. Слова «удалили», «стёрли» про файлы ученика — повод остановиться и спросить курс, что произошло.
