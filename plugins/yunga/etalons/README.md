# Эталоны

Обобщённые рабочие примеры «как это может быть устроено у человека, который давно так работает». У каждого файла сверху шапка «что важно / чего не копировать»: это **чужой пример для вдохновения, а не готовый ответ**, копировать бездумно нельзя.

Все примеры вымышленные (условный человек с темами «Кофейня» и «Фотостудия»), личных данных, реальных имён, клиентов, сумм и путей в них нет — DESIGN-v1.md, раздел 9.

| Файл | Про что |
|---|---|
| `core.md` | Ядро правил поведения — общий `CLAUDE.md` |
| `system.md` | Как устроена система файлов и правил целиком: три уровня, карта, антипаттерны |
| `memory.md` | Память (один факт — один файл, индекс) и правила с `paths:` |
| `hooks.md` | Хуки-самоаудиты: три вопроса, напоминание о закрытии, сторож памяти |
| `delegation.md` | Помощники-субагенты: три роли, бриф, два живых случая |
| `workflow-patterns.md` | Командная работа нескольких помощников: смета → согласие → запуск → проверка |
| `mcp.md` | Подключённый сервис: разбор инструментов по риску, ask, честная граница защиты |
| `maintenance.md` | Обслуживание: получасовая сверка раз в месяц |

Парные заготовки для заполнения своими словами — в `../templates/`.
