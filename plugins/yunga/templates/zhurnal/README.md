# Судовой журнал

Рабочая тетрадь курса «Юнга». Курс живёт в плагине Claude Code и может обновляться или удаляться — эта папка нет. Она лежит отдельно от `~/.claude`, переживёт удаление плагина и переезд на новый компьютер (копированием).

Открыл папку через полгода и не помнишь, что это, — вот что где лежит.

| Файл / папка | Что там |
|---|---|
| `progress.md` | модуль, шаг, что пройдено |
| `profile.md` | кто ты, как курс тебя видит, твои проекты |
| `plan.md` | три ближайших шага, история пересчётов |
| `decisions.md` | решения о твоей системе — и почему так |
| `changes.md` | правки в настройках: бэкап и откат |
| `passport.md` | «что у меня стоит» и как выключить |
| `inbox.md` | мысли и вопросы на потом |
| `capsule.md` | закладка: на чём остановились |
| `journal/` | дневник, по файлу на занятие (появится позже) |
| `pesochnica/` | только учебные проверки, настоящее не трогает |
| `Архив/` | отработавшее, ничего не удаляется |
| `backups/` | копии файлов перед правками |
| `.gitignore` | чтобы бэкапы не попадали в git |

Папки `journal/`, `pesochnica/`, `Архив/`, `backups/` появляются по первой надобности.

Диск главнее записи: `progress.md` говорит одно, а на деле другое — нормально, план пересчитается.

**Продолжить курс:** открой Claude Code в этой папке и скажи «продолжим курс» — он найдёт, где вы остановились, по `progress.md` и `capsule.md`.

**Если курса больше нет, а журнал остался** — это по-прежнему твои записи. `profile.md`, `decisions.md`, `passport.md`, `changes.md` написаны так, чтобы быть понятными и без курса: это описание твоей системы, не курса.
