# Шаблоны

Заготовки с пустыми местами `[впиши сюда...]` — ученик заполняет их своими словами на уроке. Парные разобранные примеры — в `../etalons/`.

| Файл | Про что | Пара в эталонах |
|---|---|---|
| `claude-user-core.md` | Своё ядро правил (`CLAUDE.md` в домашней папке) | `core.md` |
| `navigator.md` | Карта «где что лежит» | `system.md` |
| `rule-paths.md` | Правило для определённого вида файлов (поле `paths:`) | `memory.md` |
| `capsule.md` | Капсула задачи — записка «для себя завтрашнего» | `hooks.md`, `memory.md` |
| `skill-wrap/SKILL.md` | Скилл «ритуал закрытия» | `memory.md` |
| `hooks/tri-voprosa.sh`, `hooks/tri-voprosa.ps1` | Хук «три вопроса перед ответом» — для sh и для PowerShell 5.1 | `hooks.md` |
| `agent-scout.md`, `agent-writer.md`, `agent-reviewer.md` | Три роли помощников: разведчик, писатель, проверяющий | `delegation.md` |

Ещё не написаны (этап 0): `permissions-starter.json`, `permissions-mostai.json` и прочие из DESIGN-v1.md, раздел 7.1.
