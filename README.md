# yunga

> ⚠️ **В сборке — не устанавливать.** Плагин ещё в разработке (этап 0: каркас). Манифесты и скиллы — заглушки, уроков пока нет.

Курс-плагин онбординга в Claude Code для почти не программирующих. Наставник внутри Claude Code: плагин несёт сценарий, уроки, процедуры и эталоны; технику делает Claude, ученик решает и сам проверяет.

## Для кого

Для тех, кто почти не программирует, но хочет уверенно пользоваться Claude Code: разобраться в модели и режимах разрешений, защитить секреты и деньги от случайных трат, навести порядок в документации и памяти, подключить скиллы, MCP и субагентов, а на финальной ступени — безопасно пользоваться хуками и workflow.

Три ступени: 1 «Юнга» (самостоятельность) → 2 «Матрос» (инструменты) → 3 «Штурман» (автоматика). После каждой — работающая система и мини-выпуск; остановиться после любой ступени — нормально.

## Требования

- Claude Code ≥ 2.1.260 (`claude --version`).
- Действующая подписка Claude (Pro/Max/Team) — курс не отправляет платных запросов без явного согласия ученика.
- Для установки из git — установленный `git`; без git — установка архивом (после этапа 0.5).

## Установка

Маркетплейс курса добавляется по полному HTTPS-адресу репозитория:

```
/plugin marketplace add https://github.com/Pianist13r/yunga.git
```

```
/plugin install yunga@kubrik
```

Короткая форма `owner/repo` не подходит: она клонируется по SSH. Путь установки
без терминала и без git описывается отдельно — он проверяется на этапе 0.5.

## Запуск

После установки — команда:

```
/yunga:start
```

Без аргументов открывает меню (продолжить, карта, мини-выпуск, диагностика).

## Удаление

Журнал ученика (`~/yunga-zhurnal/`) плагином не управляется и не удаляется вместе с ним.

```
claude plugin uninstall yunga@kubrik --keep-data
```

`--keep-data` сохраняет каталог данных плагина (`~/.claude/plugins/data/yunga-kubrik/`, там лежит только указатель на журнал).
