| Команда | Итог |
|---|---|
| `/context` | работает — отчёт в чат, с разбивкой по каждому скиллу и MCP-инструменту |

Важно для уроков: **предсказать доступность по документации нельзя.** Правило «команда без аргументной формы отвечает `isn't available in this environment`» не работает — `/status` и `/usage` без аргументов и работают, `/memory` без аргументов и отказала. Отказ клиента попадает в транскрипт (`local-command-stdout`), успешно открытая панель — нет: по истории проверяется только отказ.
