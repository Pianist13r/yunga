## Slash-команды в Code-вкладке Desktop (P4, 18.09.2026, Claude Code 2.1.273)

| Команда | Итог |
|---|---|
| `/context` | работает — отчёт в чат, с разбивкой по каждому скиллу и MCP-инструменту |
| `/status` · `/usage` · `/model` · `/mcp` · `/rewind` · `/resume` | работают — открывают свою панель |
| `/init` · `/fewer-permission-prompts` | работают — это встроенные скиллы |
| `/memory` | **недоступна**: `/memory isn't available in this environment.` |
| `/config` · `/doctor` · `/hooks` · `/permissions` | **недоступны** — терминально-панельные |
| `/skill-doctor` · `/deep-research` | не проверено (в списке скиллов сессии Desktop их нет) |
| `/effort` · `/btw` · `/recap` · `/agents` · `/reload-plugins` · `/add-dir` · `/compact` · `/clear` | не проверено |

Важно для уроков: **предсказать доступность по документации нельзя.** Правило «команда без аргументной формы отвечает `isn't available in this environment`» не работает — `/status` и `/usage` без аргументов и работают, `/memory` без аргументов и отказала. Отказ клиента попадает в транскрипт (`local-command-stdout`), успешно открытая панель — нет: по истории проверяется только отказ.
